## 🎨 Modern Cyber Design System

- **Electric Cyber Blue Palette**:
  - Primary Accent: `#00d2ff` (Electric Cyan)
  - Glow & Secondary: `#0070f3` (Azure Neon)
  - Subtle Borders & Depth: `#0a2540` / `rgba(0, 210, 255, 0.25)`
  - Dark Obsidian / Slate Backdrop: `#0b0f19` and `#0f172a`
- **Dynamic Title Decryption**: Terminal character scramble-in effect on page load with scanline sweep and refined micro-glitch on hover.
- **Interactive Canvas Mesh**: Lightweight, 60fps constellation particle network connecting neighboring cyber nodes with mouse interactivity.
- **Glassmorphic DevSecOps Terminal**: Linux terminal component displaying `profile.json` with syntax highlighting and window controls.
- **Pixel-Perfect Responsive Layout**: Mobile drawer navigation (44x44px touch targets), fluid clamp typography, and zero horizontal overflow on screens down to 360px.
